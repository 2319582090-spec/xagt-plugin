## Description

An X-Agent copy-trade research assistant that scans high-return on-chain opportunities, applies risk gates, and generates an OKX wallet-confirmed trade plan.

The project is designed for the Build with XAgent x OKX hackathon. It maps the copy-trade workflow to `okx-dex-signal` for signal discovery, `okx-security` for risk scanning, `okx-dex-swap` for quote and route preparation, and `okx-agentic-wallet` for wallet-confirmed execution. The demo stays in plan-only mode and does not custody keys or broadcast trades without user wallet confirmation.
